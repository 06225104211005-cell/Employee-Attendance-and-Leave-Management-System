Project name: Attendance

1. Quick use: open website-source/Attendance.html directly. It is a single self-contained HTML file.
2. Separate source: keep website-source/index.html, style.css and app.js together, then open index.html in a browser.
3. Lab report: use lab-report/Lab_Report.pdf or edit lab-report/Lab_Report.docx before submission.

The project includes synthetic employee portraits, English and Bangla names, dashboard, employee directory, attendance register, leave form and responsive design.
